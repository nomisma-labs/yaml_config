The toolchain and copied scaffold files use MIT. The notice is in
[cmake/kit/LICENSE](../../../cmake/kit/LICENSE); initialization also uses it for MIT project code.

`LicenseRef-Sustainable-Use-1.0.txt` contains the unmodified Sustainable Use License 1.0
section from the [license author's text](https://github.com/n8n-io/n8n/blob/master/LICENSE.md#sustainable-use-license).
It excludes n8n's repository-specific enterprise and branch exclusions. Initialization adds
the selected project's copyright holder and scope separately. `LicenseRef-Sustainable-Use-1.0`
is the local SPDX reference used by this kit.

The proprietary option uses the existing Nomisma notice granting no permission without the
copyright holder's written consent. These choices apply to project-owned material according
to `project_license.json`; carrying a license text in this catalog does not apply it to the kit.
